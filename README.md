# Early stopping как итерационная регуляризация

Код к курсовой работе по теме "Ранняя остановка, регуляризация Тихонова и спектральная фильтрация".

## Файлы репозитория

| Файл | Описание |
|------|----------|
| `SLP.py` | Эксперимент 1: линейная регрессия с плохо обусловленной матрицей |
| `KRR.py` | Эксперимент 2: kernel ridge regression на sin(x) |
| `MLP.py` | Эксперимент 3: MLP на MNIST, сравнение с L2-регуляризацией |
| `seed.txt` | Фиксированный seed для воспроизводимости |
| `requirements.txt` | Зависимости |

## Запуск

```bash
pip install -r requirements.txt
python SLP.py
python KRR.py
python MLP.py
```

## Результаты

После запуска каждого скрипта в текущей папке появляются графики:

| Скрипт | Создаваемый файл |
|--------|------------------|
| `SLP.py` | `slp_result.png` |
| `KRR.py` | `krr_result.png` |

## Правила остановки

Во всех экспериментах сравниваются три правила:

- **Hold-out**: остановка после 3 последовательных увеличений валидационной потери
- **Ratio**: остановка при относительном изменении потерь ниже порога
- **Априорное**: остановка на фиксированной эпохе (15, 40, 15)

Конкретные пороги и параметры указаны в каждом скрипте.

## Воспроизводимость

Seed сохраняется в `seed.txt`. При первом запуске генерируется случайный seed, при повторных используется тот же. Это обеспечивает одинаковые результаты при повторных запусках.
